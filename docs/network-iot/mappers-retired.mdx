Helium Mappers, the IoT coverage mapping service at `mappers.helium.com`, was shut down in
November 2026. The website, the Mappers API that device integrations sent uplinks to, and the
coverage tile server are no longer available, and the data they served is no longer published.

The source code remains available, read-only, in the archived
[helium/mappers](https://github.com/helium/mappers) repository.
